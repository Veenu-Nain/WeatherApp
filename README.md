# Weather App

Welcome to the **Weather App**! This is a simple web application that allows users to check the current weather conditions for any city around the world. It fetches real-time weather data from a third-party weather API and displays it in an easy-to-read format.

## Features

- **Search for any city**: Enter the name of a city to get its current weather details.
- **Displays current temperature, humidity, and weather condition**: Shows key weather metrics like temperature, humidity, and weather description (e.g., clear sky, rain).
- **Responsive design**: The app is fully responsive, making it easy to use on both desktop and mobile devices.
- **Error handling**: Displays error messages if the user enters an invalid city or if there are issues fetching the data.

## Technologies Used

- **HTML5**: For the structure and layout of the application.
- **CSS3**: For styling the app and ensuring it's responsive.
- **JavaScript**: For handling the logic, fetching data from the weather API, and updating the UI dynamically.
- **OpenWeatherMap API**: A free weather API used to fetch real-time weather data.
- **API Key**: You need your own API key from OpenWeatherMap to run the app.
